# WinDbg Window Marker Cheat Sheet (Hip Curve Mapping)
# Purpose: add action context markers without changing packet-capture logic.
# Use with your existing capture breakpoints and filters.

# -----------------------------------------------------------------------------
# Global pattern for each window
# -----------------------------------------------------------------------------
# 1) Reset baseline to Preset 4 in UI.
# 2) Run baseline save (no movement).
# 3) Perform one action only.
# 4) Run action save.
# 5) If mishap occurs, mark it and reset to Preset 4.

# Optional precision annotation format for any action marker:
#   start=<point/segment id or visual anchor>; target=<intended destination>; actual=<where it ended>
# Example:
#   .echo [H-T2-W01] action square edit; start=mid-handle; target=right-flat; actual=right-wall-then-slight-right

# Optional per-window raw log:
# .logopen /t c:\tmp\Prometheus-XIM\examples\captures\raw\H-T2-W01.log
# ... run window ...
# .logclose

# -----------------------------------------------------------------------------
# H-T2-W01 (Square edit)
# -----------------------------------------------------------------------------
.echo [H-T2-W01] baseline preset4 selected, Tool2 square mode, about to press Save
g
.echo [H-T2-W01] action square edit; start=<point>; target=<destination>; actual=<result>, about to press Save
g
.echo [H-T2-W01] complete

# Mishap branch (only if needed)
.echo [H-T2-W01] mishap overshoot/misclick; discard window and reset preset4
g
.echo [H-T2-W01] reset complete; canonical rerun starts now
